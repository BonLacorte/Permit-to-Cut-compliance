Add the Permit-to-Cut / RA 8048 compliance project to the resume under the existing work experience entry:

This should read as an extension of the Internal Audit Department System work, not as a separate unrelated project. The best placement is directly after the current Internal Audit Department System bullets, because it is another audit-focused internal tool built for PCA operations.

## Notes On Wording
- Use **RA 8048 Audit Tool** instead of only **Permit-to-Cut Compliance App** because it sounds more domain-specific and audit-focused.
- Keep **Next.js, TypeScript, Prisma, PostgreSQL, Vercel** in the tech stack line because those are stronger current full-stack keywords.
- Avoid listing every feature. The resume should highlight outcomes: centralized records, versioned audit rules, reporting, and production deployment.
- Do not overstate metrics unless we have real numbers. We can mention the 288 production records only if you want a concrete number, but it may sound small compared with your OPFRS 2.7 million record bullet.
